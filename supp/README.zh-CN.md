# 补充图 S1–S14

[返回仓库首页](../README.zh-CN.md)

每个绘图模块都提供 `draw(...)` 函数。按下表传入相应的数据表、估计值或系统发育树对象。Python 函数返回 Matplotlib 图形，可用 `fig.savefig("output.pdf")` 保存。在 R 中用 `source()` 加载所选脚本，调用 `draw(...)` 后用 `ggplot2::ggsave("output.pdf", plot = fig)` 保存返回的图形。输出文件名由调用者指定。

| 图号 | 图示内容 | 模块与所需输入 |
| --- | --- | --- |
| S1 | 各样本比对至病毒目录的读段比例、vOTU 检出数、序列长度和 CheckV 基因计数 | [S01.py](S01.py) 读取样本质控表、目录序列长度、病毒与宿主基因计数，以及标注文字、标注对象坐标和文字位置。 |
| S2 | 逐一剔除预测裂解型成员后的效应估计，以及丰度贡献最大的 12 个成员 | [S02.py](S02.py) 读取逐一剔除 vOTU 后的估计值与区间、成员贡献表，以及完整模型的系数。 |
| S3 | 不同敏感性分析中各病毒生活方式类别的组间差异 | [S03.py](S03.py) 读取按分析情景、生活方式类别和协变量调整方式整理的估计值、区间、P 值和 q 值，并按显示顺序传入四个情景的标识及标签。 |
| S4 | Shannon 多样性、基于 Bray–Curtis 和稳健 Aitchison 距离的排序图，以及与严重程度相关的变异比例 | [S04.py](S04.py) 读取各样本的 Shannon 指数、调整后模型的汇总结果行和分组标签。每种距离还需传入一个元组，依次包含排序坐标、PERMANOVA 结果、组内离散度检验结果和椭圆的几何参数。 |
| S5 | 单个 vOTU 的差异丰度，以及探索性候选成员（q < 0.25）的基因计数 | [S05.py](S05.py) 读取完整的差异分析结果、入选候选表和模型样本量。候选表需含估计区间、预测宿主属和 CheckV 基因计数。 |
| S6 | 临床表型与病毒组特征的关联，以及原始 P 值最小的十项关联的估计区间 | [S06.R](S06.R) 读取各表型与特征组合的效应估计、95% 置信限、原始 P 值、BH 校正 q 值和有效样本量。 |
| S7 | 病毒与细菌的共丰度矩阵，标出与预测宿主匹配的位置 | [S07.py](S07.py) 要求每个细菌与 vOTU 组合对应一条检验记录，包含 Spearman ρ、按整个矩阵作 BH 校正的 q 值和宿主匹配标注。另需指定横轴上标出哪些列的序号。 |
| S8 | 各情景下 *Escherichia* 的严重程度组间差异，以及逐一剔除成员后宿主共丰度相关性的变化 | [S08.py](S08.py) 读取各情景的效应估计、相关系数及相应区间、逐一剔除成员后的 ρ 变化值，以及四个情景的标识与标签和需高亮的成员标识。 |
| S9 | 各标记基因树及其节点支持度汇总 | [S09.py](S09.py) 要求每个标记对应一行，包含任务标识、末端数、修剪后氨基酸比对长度、所选模型，以及 SH-aLRT 和 UFBoot 支持度。 |
| S10 | 六棵完整的标记基因树 | [S10_S12_S13.py](S10_S12_S13.py) 每次绘制一棵已有树，每棵占一页。设 `view="full"` 并保留 `chosen=None`，即可显示全部末端。 |
| S11 | 病毒代表序列上的基因排列 | [S11.R](S11.R) 读取基因坐标、方向和功能类别、代表序列长度、文字标注坐标、各分图标题和配色。需要标注裂解相关区段或补充说明时，通过相应数据表和文字传入。 |
| S12 | 末端酶大亚基（TerL）系统发育树的局部邻域 | [S10_S12_S13.py](S10_S12_S13.py) 接受已有树，并通过 `chosen` 传入所选末端名称的集合。设 `view="local"` 可显示该邻域，并汇总省略的分支。 |
| S13 | 三棵完整的标记基因树 | [S10_S12_S13.py](S10_S12_S13.py) 逐棵绘制已有树，参数为 `view="full"` 和 `chosen=None`。 |
| S14 | 携带耐药、辅助代谢或毒力基因的病毒丰度，以及各辅助代谢基因类别的组间差异 | [S14.py](S14.py) 读取功能模型结果表、带严重程度分组和分图编码的各参与者样本中携带相应基因的病毒丰度，以及分组标签。 |

Python 依赖 Matplotlib、NumPy 和 pandas。请将 `supp/` 加入 Python 模块搜索路径，以便绘图模块加载 [supp_style.py](supp_style.py) 中的字体和配色设置。`canvas(height_mm)` 创建宽 175 mm 的画布，`panel(ax, letter, title, ...)` 添加分图字母和标题。S10、S12 和 S13 另需 Biopython。三图共用的函数接受含枝长和节点支持度的树、目标末端名称、所有末端的注释、两种支持度指标的顺序，以及页面标题。S6 使用 ggplot2 和 patchwork，S11 使用 ggplot2 和 gggenes。

本目录提供绘图源码。研究记录、拟合结果、参考树和成品图另行保存。函数所需的成员归属、计数、结果文字和图件标识均由调用者提供。序列核查、序列比对、系统发育树推断和模型拟合均在绘图之前完成。
